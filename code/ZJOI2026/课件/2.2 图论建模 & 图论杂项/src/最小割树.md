# 最小割树

给定一张图，求出一棵树，满足：

1. 对于图上任意一对点，两点之间的最小割等于树上两点之间的最小割，即树上路径边权最小值
2. 对于树上任意一条边 $(u,v)$，去掉 $(u,v)$ 后两个连通块是一组最小割的方案

一般求的是简化版，只满足第一个要求，即 **等价流树**

## 建立等价流树：Gusfield 算法

对点集分治，任取其中两点在原图上求出这两点之间的最小割，在树上连接两点，边权为最小割

按一组最小割将目前点集划分为两部分后递归处理

只需要 $n-1$ 次求最小割的操作即可完成建树

模板题：[P4897 【模板】最小割树（Gomory-Hu Tree）](https://www.luogu.com.cn/problem/P4897) $\quad$ [代码](https://www.luogu.com.cn/record/255825483)

## 例 1：[CF343E Pumping Stations](https://www.luogu.com.cn/problem/CF343E)

先求出最小割树，转化为找到树上结点的一个排列，满足相邻点对权值之和最小，其中一对点的权值定义为树上两点之间路径上边权的最小值

取出权值最小的边 $(u,v)$，则只会跨越它至多一次

证明：设 $(x,y)$ 和 $(p,q)$ 都跨越了 $(u,v)$，其中 $x,p$ 都在 $u$ 一侧，完整路径为 $(P_1)-x-y-(P_2)-q-p-(P_3)$，则调整为 $(P_1)-x-p-(P_3)-y-(P_2)-q$ 一定不劣

由此容易构造方案
