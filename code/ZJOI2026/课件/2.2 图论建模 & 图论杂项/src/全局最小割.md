# 全局最小割

给定无向图 $G=(V,E)$，令 $f(S)=\sum_{(u,v,w)\in E}[u\in S][v\notin S]w$，求出 $\min_{\varnothing\subset S\subset V} f(S)$

## Stoer-Wagner 算法

考虑每次找出一对点 $s,t$，求出两者间最小割跟新答案，然后将 $s$ 和 $t$ 并起来，并继续处理

问题转化为如何快速找出 $(s,t)$，使用最大邻接排序算法（$\text{Maximum Adjacency Ordering}$）

初始 $S=\varnothing$，对于每个点 $u\in V$，维护 $d_u$，表示 $\sum_{(u,v,w)\in V}[v\in S]w$

每次选择 $V/S$ 中 $d$ 最大的点，加入 $S$

根据每个点加入 $S$ 的顺序，得到一个序列，取序列最后两个元素作为 $(s,t)$，两者之间的最小割即为最后一点加入 $S$ 前的 $d$

可以用 $\text{dijkstra}$ 算法实现这一过程，每一轮可以做到 $O(n^2)$ 或 $O((m+n)\log n)$，用斐波那契堆可以做到 $O(m+n\log n)$

总时间复杂度 $O(n^3)$ 或 $O(n(m+n)\log n)$ 或 $O(mn+n^2\log n)$
