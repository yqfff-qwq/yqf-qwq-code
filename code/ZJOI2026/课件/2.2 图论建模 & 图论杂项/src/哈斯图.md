# 哈斯图

## 定义

二元关系：对于集合 $S$，称 $R\subseteq S^2$ 为二元关系，对于 $u,v\in S$ 若 $(u,v)\in R$ 则称 $u,v$ 满足二元关系 $R$，记为 $u R v$

自反性：对于二元关系 $\preceq$，若任意 $a\in S$ 都满足 $a\preceq a$，则称其满足自反性

反对称性：对于二元关系 $\preceq$，若不存在 $a,b\in S$ 使得 $a\ne b$ 且 $a\preceq b,b\preceq a$，则称其满足反对称性

传递性：对于二元关系 $\preceq$，若任意 $a,b,c\in S$ 满足 $a\preceq b\preceq c$，都满足 $a\preceq c$，则称其满足传递性

偏序关系：若二元关系满足自反性、反对称性、传递性，则称其为偏序关系

偏序集：集合 $S$ 和定义在 $S$ 上的偏序关系 $R$，记为 $(S,R)$

覆盖元素：对于 $x<y$ 且不存在 $z$ 使得 $x<z<y$，则称 $y$ 是 $x$ 的覆盖元素

哈斯图：若 $y$ 是 $x$ 的覆盖元素则连有向边 $x\to y$，得到的图称为哈斯图

可比：若 $a,b\in S$ 满足 $a\preceq b$ 或 $b\preceq a$，则称 $a,b$ 可比

链：$S$ 两两可比的子集

反链：$S$ 两两不可比的子集

## 性质

由于偏序关系满足反对称性，哈斯图不存在回路，因此哈斯图为 $\text{DAG}$

拓扑排序本质上是构造一个相容的全序

## 相关定理

**$\text{Dilworth}$ 定理**：对于任意有限偏序集，其最大反链大小等于最小链覆盖大小

**$\text{Mirsky}$ 定理**：对于任意有限偏序集，其最大链大小等于最小反链覆盖大小

**$\text{Erd\"os–Szekeres}$ 定理**，含至少 $(r-1)(s-1)+1$ 个元素的实数序列 $\{a_i\}$，要么有一个长为 $r$ 的不降子序列，要么有一个长为 $s$ 的不升子序列

三者都可用杨表理解
