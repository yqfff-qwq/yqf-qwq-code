# BEST 定理

对于有向欧拉图 $G$，令 $k$ 为任意顶点，则 $G$ 不同的欧拉回路总数 $\text{ec}(G)$ 为

$$
\text{ec}(G) = t^{root}(G,k) \prod_{v\in V} (\text{deg}(v)-1)!
$$

其中 $\text{deg}$ 表示度数（由于有向欧拉图出度入度相等，因此略去上标），$t^{root}(G,k)$ 表示 $G$ 中以 $k$ 为根的根向基环树的数量

即求出一棵生成树后，钦定所有非树边的顺序（为了避免重复计数循环同构的，根处需要特殊处理），欧拉回路的构造为从根出发，先按顺序走非树边，最后走树边，可证必然能得到回路且两者构成双射

对于半欧拉图的欧拉路计数，显然可以转化为欧拉图的欧拉回路计数
