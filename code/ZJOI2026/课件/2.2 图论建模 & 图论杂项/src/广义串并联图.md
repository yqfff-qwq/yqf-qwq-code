# 广义串并联图

**广义串并联图** 指不存在同胚于 $K_4$ 的子图的图，可以通过删一度点，缩二度点，叠合重边变为单点

去掉重边后必有 $|E|\le 2|V|$

任意简单广义串并联图都可通过以下方式构造：

1. 初始只有一个单点
2. 每次新增一个点，选择原本图中某一点与之相连
3. 每次选择一条边，新增一点与两者相连，并选择是否删去原来的边

## 广义串并联图方法

对于任意一张图，令 $k=|E|-|V|$，经过若干次删一度点，缩二度点的操作，显然 $k$ 不变，且操作到最后要么 $|V|=1$ 要么每个点度数 $\le 3$，对于后一种情况 $2|E|\le 3|V|$，从而 $|V|\le 2k,|E|\le 3k$

### 例：[AT_abc419_g [ABC419G] Count Simple Paths 2](https://www.luogu.com.cn/problem/AT_abc419_g)

删去除 $1$ 和 $n$ 外的一度点，缩二度点，得到的图点数 $O(m-n)$，显然整张图只有至多 $O(2^{m-n})$ 条从 $1$ 到 $n$ 的简单路径，暴力即可，时间复杂度 $O((n+m)\log (n+m)+(m-n)2^{m-n})$
