# 平面图

图 $G$ 为 **平面图** 当且仅当可以将图在拓扑不变的情况下展开到平面上，且所有边不交

$K_{3,3}$ 为边最少的非平面图，$K_5$ 为点最少的非平面图

$G$ 展开到平面上后，边将整个平面划分为若干区域，其中面积无限的面称为 **无限面** 或 **外部面**，面积有限的面称为 **有限面** 或 **内部面**

对于一个面，包围这个面的所有边构成的回路称为这个面的边界，边界包含的边的数量称为这个面的 **次数**

## 平面图欧拉公式

**符号**：

- $V$：点数
- $E$：边数
- $P$：有界面数
- $B$：连通块数

**欧拉公式**：$$V-E+P=B$$

### 推论

- 若所有面次数不超过 $L$，则 $E\le \frac 1{L-2}(V-B-1)$

- $E\le 3V-6$

  证明：

  - 每条边有左右两侧，一共 $2E$ 个“侧”，每个面至少对应其中三个，因此 $2E\ge 3(P+1)$（加一是考虑无界面）
  - 结合 $V-E+P=B\ge 1$ 可得 $E\le 3V-6$

- 对于任意简单平面图，存在一种定向方式，使得每个点出度不超过 $5$

  取到上界的例子：正二十面体的平面展开

  证明：

  - 设点为 $1\sim V$，它们的度数为 $d_{1\sim V}$，则有 $\sum_{i=1}^V d_i=2E\le 6V-12$
  - 从而必然存在一个 $d_u\le 5$，删去它后递归处理，按拓扑序连边即可

## 库拉托夫斯基定理

**内容**：一张图是平面图当且仅当不含与 $K_{3,3}$ 或 $K_5$ 同胚的子图

由此可以在多项式时间内判定一张图是否为平面图

$\text{Hopcroft-Tarjan}$ 算法可以做到 $O(n)$

## 对偶图

对于平面图 $G$，构造其对偶图 $G'$：

- 对于 $G$ 中每个面，在 $G'$ 中建立一个点
- 对于 $G$ 中每条边，找到它对应的左右两个面，在 $G'$ 中将这两个面对应点连边

显然对偶图也是平面图，且原图的点边面分别对应对偶图的面边点

### 最小左转法

用于平面图转对偶图，要求给定每个点的坐标，且边都是直线

每条无向边拆分为左右两条有向边，显然每条有向边恰好属于一个面（包含无界面）

对于每个点，将其所有出边根据幅角排序

对于每条有向边，在它指向的点中二分找到它左侧第一条出边（精细实现应该可以做到线性），称这条边为其后继边

每条边连向其后继边，则得到若干环，显然每个环都是一个面

取出所有环，分配一个面，连边是容易的

时间复杂度 $O(n\log n)$

### 例：[P3249 [HNOI2016] 矿区](https://www.luogu.com.cn/problem/P3249) $\quad$ [LOJ #2052. 「HNOI2016」矿区](https://loj.ac/p/2052)

先求出对偶图，以无界面为根找到一棵生成树，每个点保存子树内面积之和，面积的平方之和

对于一组询问，枚举给定的边界上的边，在树上找到它对应的边，确定左右分别位于边界的哪一侧，并确定计入答案的符号

时间复杂度 $O(n\log n+\sum d\log n)$
