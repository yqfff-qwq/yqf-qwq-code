# 耳分解与双极定向

## 耳分解

对于图 $G=(V,E)$（可以是有向图，也可以是无向图）和其子图 $G'=(V',E')$，$V'\subsetneq V$，称路径（可以为环）$x_{1\sim k}$ 为 **耳** 当且仅当 $x_1,x_k \in V'$ 且 $x_{2\sim k-1}\in V/V'$ 且 $x_{2\sim k-1}$ 两两不同

若 $x_1\ne x_k$ 则称为 **开耳**

图 $G$ 的 **耳分解** 为子图序列 $G_{0\sim k}$，满足 $G_0$ 为环，$\forall 0\le i<k,G_i\subsetneq G_{i+1}$，$G_k=G$，$\forall 1\le i\le k$，$G_i/G_{i-1}$ 为 $G_{i-1}$ 的耳

若这些耳都是开耳，则称为 **开耳分解**

## 耳分解与双连通性

一张图边双连通当且仅当图可耳分解

一张图点双连通当且仅当图可开耳分解

构造：

- 找出任意一棵 $\text{DFS}$ 生成树
- 任选一个从根开始仅含一条非树边的环作为 $G_0$，之后保持 $G_i$ 为树上一个含根的连通块
- 若目前子图的点集等于全集，则将所有还没有加入的边各自作为一个耳即可
- 若点集不等于全集，则找到点 $x$ 使得 $x$ 不在子图中但 $fa_x$ 在子图中
- 找到一条覆盖 $(x,fa_x)$ 的返祖边 $(u,v)$ 满足 $u$ 在子树 $x$ 中且 $v$ 为 $fa_x$ 的祖先（对于双连通图必然可以找到这样一条边，对于点双连通图必然可以使 $v$ 为 $fa_x$ 的严格祖先），加入耳 $fa_x-x-\cdots-u-v$

时间复杂度为 $O(n^2)$

## 耳分解与强连通性

一张无向图可定向为强连通图当且仅当图边双连通，具体构造为耳分解后每个耳定向为一条有向路径

## 双极定向

对于一张无向图和给定的点对 $(s,t)$，以下四个命题等价：

1. 添加边 $(s,t)$ 后图点双连通
2. 图的圆方树上方点成一条链，且 $s\to t$ 为树的直径
3. 存在一种定向方式使得 $s$ 为唯一无入度点，$t$ 为唯一无出度点
4. 存在点的排列，使得任意前缀后缀的导出子图连通

$1$ 和 $2$ 之间显然等价，$3$ 到 $4$ 取拓扑序即可，$4$ 到 $3$ 按拓扑序定向即可

$1$ 到 $3$ 先求出开耳分解，容易使得 $(s,t)$ 在初始的环 $G_0$ 上，容易定向环上剩余边，每加入一个耳按两端点之间的偏序关系给耳定向

### 构造双极定向

基于耳分解的算法为求出开耳分解后暴力定向，可以做到 $O(n^2)$

对于每个点，在 $\text{DFS}$ 树上，只保留子树内到其祖先的返祖边中终点深度最浅的，此时叶子必然为二度点，收缩起来，并重复这一过程，显然最终会剩下一条 $s-t$ 的链，容易完成定向

具体实现为：在 $\text{DFS}$ 树上，按从下往上的顺序枚举 $s-t$ 路径之外的点，将点 $u$ 加入 $\text{low}_u$ 对应点和 $\text{fa}_u$ 的备选队列中，然后从 $s$ 到 $t$ 枚举链上点，走到点 $u$ 后再遍历 $u$ 的备选队列中的点（若已经遍历过则跳过），得到的序列满足任意前缀后缀导出子图连通，容易由序列构造双极定向

时间复杂度 $O(n+m)$

## 例：[P9394 白鹭兰](https://www.luogu.com.cn/problem/P9394)

建立圆方树，等价于在圆方树上选择两个叶子 $x,y$，在 $x-y$ 路径上所有方点处断开，最小化所有连通块中圆点数量的最大值

树形 $dp$ 后用双极定向构造方案即可

时间复杂度 $O(n+m)$
