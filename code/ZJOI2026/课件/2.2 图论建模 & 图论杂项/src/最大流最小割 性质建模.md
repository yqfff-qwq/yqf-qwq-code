# 最大流最小割 性质建模

最大流最小割定理：**最大流等于最小割**

最大流建模时常将流作为移动，路径作为选择

最小割建模时常将被割边当作删除元素或划分集合

删元素时，一般将每个点拆为入点和出点，入点向出点连边，割开这条边相当于删除这个元素

## 集合划分模型

形式：将若干元素划分为两个集合 $S_1,S_2$，最小化 $\sum_{u\in S_1}\sum_{v\in S_2} c_{u,v}+\sum_{u\in S_1} a_u+\sum_{u\in S_2} b_u$，要求 $a,b,c$ 都为非负数

建立 $n$ 个点，源点向每个 $u$ 连边权 $b_u$ 的边，每个 $u$ 向汇点连边权 $a_u$ 的边，每个 $u$ 向 $v$ 连边权 $c_{u,v}$ 的边

求出最小割即为最小代价，具体划分方案为：与源点相连的部分为 $S_1$，与汇点相连的部分为 $S_2$

## 最大权闭合子图

定义：一个子图为闭合子图当且仅当其缩点后出度为 $0$

形式：给定一张图，有点权 $w_i$，选择一个闭合子图使点权和最大

尝试使用之前的划分模型，设 $S_1$ 为选出部分，$S_2$ 为不选的，则 $a_u=w_u$，$b_u=0$，$c_{u,v}=-\infty$，要求总和最大

翻转得到 $a_u=-w_u$，$b_u=0$，$c_{u,v}=+\infty$，要求总和最小，相反数即为答案

当 $w_u>0$ 时 $a_u<0$，容量为负，无法处理

因此预先加上所有 $>0$ 的 $w_u$，对应的 $a_u$ 变为 $0$，$b_u$ 变为 $w_u$

因此建图方式为：

- 对于 $w_u>0$ 的 $u$，源点向 $u$ 连边容量 $w_u$，$u$ 向汇点连边容量 $0$（省略之）
- 对于 $w_u\le 0$ 的 $u$，源点向 $u$ 连边容量 $0$（省略之），$u$ 向汇点连边容量 $-w_u$
- 对于原图每条边 $u\to v$，网络中 $u$ 向 $v$ 连边容量 $+\infty$
- 答案为 $\sum[w_u>0]w_u-\text{min\_cut}$

## 广义切糕模型

形式：存在 $x_{1\sim n}$，$x_i\in[1,m_i]\cap\mathbb Z$，$x_i$ 取 $j$ 时有 $w_{i,j}$ 的代价，$q$ 组限制 $x_i-x_j<k$ 或 $x_i-x_j>k$，求最小总代价

每个 $x_i$ 拆为 $p_{i,0\sim x_i}$ 这 $x_i+1$ 个点，$p_{i,j-1}$ 向 $p_{i,j}$ 连边权 $w_{i,j}$ 的边，割掉这条边表示令 $x_i=j$，源点向 $p_{i,1}$ 连边 $+\infty$，$p_{i,m_i}$ 向汇点连边 $+\infty$，表示两者不能割

所有 $p_{i,j}$ 向 $p_{i,j-1}$ 连 $+\infty$ 的边（为了传递限制）

对于 $x_i-x_j\le k$ 的限制，所有 $p_{i,v}$ 向 $p_{j,v-k}$ 连 $+\infty$ 的边（强制令 $p_{i,v}$ 与汇点的连通情况和 $p_{j,v-k}$ 与源点的连通情况不同）

对于 $x_i-x_j\ge k$ 的限制，所有 $p_{j,v}$ 向 $p_{i,v+k}$ 连 $+\infty$ 的边（**若 $v+k>m_i$ 则连向汇点**）

最小割即为答案

### 例 1：[P3227 [HNOI2013] 切糕](https://www.luogu.com.cn/problem/P3227)

限制为 $|f_{x,y}-f_{x',y'}|\le d$，即 $f_{x,y}-f_{x',y'}<d,f_{x',y'}-f_{x,y}<d$，$p\times q$ 个变量，$O(p\times q)$ 组限制，直接连边即可

时间复杂度 $O(pqr\sqrt{pqr})$
