# 二分图性质

## 二分图最小点覆盖 = 二分图最大匹配（$\text{K\"onig}$ 定理）

构造：求出最大匹配后，令 $S$ 为残量网络上从源点出发可达的点集，则 **左部不在 $S$ 中的点** 和 **右部在 $S$ 中的点** 构成一组最小点覆盖

其本质为最大流最小割定理：最大匹配对应最大流，最小点覆盖对应最小割

## 二分图最大独立集 = |L| + |R| - 二分图最大匹配

构造：取最小点覆盖的补集

## 二分图最大团 = |L| + |R| - 补图最大匹配

**此处补图的定义**：$G'=(V,E')$，$E'=\{(u,v)\mid u\in L,v\in R,(u,v)\notin E\}$

构造：取补图的最大独立集

## 二分图最小边覆盖 = |L| + |R| - 二分图最大匹配

构造：取所有匹配边，并对于每个非匹配点任选一条邻边

## 二分图最大匹配必经边

求出残量网络的 $\text{SCC}$，则两端点不在同一 $\text{SCC}$ 中的匹配边为 **必经边**

## 二分图最大匹配必经点

求出残量网络的 $\text{SCC}$，则 左部点中和 $S$ 不在同一 $\text{SCC}$ 中的点 和右部点中和 $T$ 不在同一 $\text{SCC}$ 中的点为 **必经点**

## 二分图最大匹配可行边

求出残量网络的 $\text{SCC}$，则 当前匹配中的边 和 两端点在同一 $\text{SCC}$ 中的边 都是 **可行边**

## 二分图最大匹配可行点

至少一条邻边为可行边的点为 **可行点**
