# 环计数问题

## 无向图三元环计数

令 $d_u$ 表示结点 $u$ 的度数，则对于所有边 $(u,v)$，定向为从 $d$ 小的连向大的（若相同则比较点的编号）

显然此时每个点出度都不超过 $O(\sqrt m)$

枚举 $u$，枚举 $u\to v$，枚举 $v\to w$，恰好遍历所有三元环 $(u,v,w)$

时间复杂度 $O(m\sqrt m)$，同样也证明了无向图三元环数量为 $O(m\sqrt m)$ 的

模板题：[P1989 【模板】无向图三元环计数](https://www.luogu.com.cn/problem/P1989) $\quad$ [代码](https://www.luogu.com.cn/record/257712749)

## 无向图四元环计数

同样按三元环的方式定向，枚举 $u$，枚举无向边 $(u,v)$，枚举 $v\to w$，答案累加 $w$ 的计数器并令计数器加一，下一个 $u$ 时清空计数器

时间复杂度 $O(m\sqrt m)$

模板题：[LOJ #191. 无向图四元环计数](https://loj.ac/p/191) $\quad$ [代码](https://loj.ac/s/2498029)
