# 费用流性质建模

随着流量递增，每一单位流量的费用单调，若要最小费用且不要求最大流，则单位费用 $>0$ 时直接结束，最大费用同理

一条边不同的流量对应不同的费用，若其函数为凸的，则可以拆为多条边放到费用流上

## 区间选择模型

形式：给定 $n$ 个区间 $[l_i,r_i]\in [1,m]$，每个区间可以选择若干次进行区间覆盖，$[l_i,r_i]$ 选择一次代价为 $w_i$，最多选 $c_i$ 次，要求点 $j\;(1\le j\le m)$ 覆盖次数在 $[a_j,b_j]$ 中，求最小 / 最大代价

令 $X$ 为极大值

建立一条链 $1\to 2\to 3\to\cdots\to m+1$，其中边 $i\to i+1$ 的流量等于 $X$ 减点 $i$ 被覆盖的次数

对于区间 $([l_i,r_i],w_i,c_i)$，$l_i$ 向 $r_i+1$ 连容量 $c_i$ 费用 $w_i$ 的边，这条边的流量表示 $[l_i,r_i]$ 被选择的次数

源点向 $1$ 连边，$m+1$ 向汇点连边，两者费用为 $0$ 容量为 $X$

对于 $i\to i+1$ 令其流量上下界为 $[X-b_i,X-a_i]$，然后求上下界最小 / 最大费用最大流即可
