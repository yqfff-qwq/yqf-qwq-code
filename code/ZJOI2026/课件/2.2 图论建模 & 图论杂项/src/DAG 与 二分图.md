# DAG 与 二分图

## DAG 最小路径划分

描述：将 $\text{DAG}$ 划分为若干路径，使得每个点都在恰好一条路径中，最小化路径的数量

对于原图中每个点 $u$，建立 $u^0$ 和 $u^1$ 两个点，原图中每条边 $u\to v$ 在新图中连接 $u^0\to v^1$（得到的图称为原图的**拆点二分图**）

**$\text{DAG}$ 最小路径划分** 等于 $n$ 减去其拆点二分图的最大匹配

构造：初始每个点为单独一条路径，对于每条匹配边，将两个端点所在路径连起来，即匹配边组成的路径就是方案

## DAG 最小路径覆盖

描述：用若干条可交路径覆盖 $\text{DAG}$ 的所有点

构造：用 $\text{Floyed}$ 传递闭包，原图最小路径覆盖等于新图最小路径划分（最小路径划分中选择的一条路径对应原图的若干条路径，选择其中任意一条）

本质上利用传递闭包跳过了被重复覆盖的点

## DAG 最长反链

描述：找到 $\text{DAG}$ 上的最大点集，使得点集中的点两两不可达

根据 $\text{Dilworth}$ 定理，最长反链等于最小路径覆盖

构造：先选路径覆盖中所有路径的终点，若选择的点中存在 $x$ 可达 $y$，则 $y$ 沿着选择的路径向起点走一步

## 例：[CF1630F Making It Bipartite](https://www.luogu.com.cn/problem/CF1630F)

题目中连边关系具有传递性，因此不能存在长度 $\ge 3$ 的链，否则产生三元环

在二分图上假定左侧连向右侧，则每个点要么只有入度，要么只有出度，拆为 $in_x$ 和 $out_x$ 分别表示两种情况

原图的边 $u\to v$，相当于 $out_u\to in_v$

即 $in_u\to in_v,out_u\to out_v,in_u\to out_u,in_v\to out_v,in_u\to out_v$ 都不合法

将这些不合法的边连上，求其最大独立集，即为最大可保留点数

显然这样建出的图是 $\text{DAG}$，最大独立集就是最长反链

需要根号分治来枚举初始的所有边
