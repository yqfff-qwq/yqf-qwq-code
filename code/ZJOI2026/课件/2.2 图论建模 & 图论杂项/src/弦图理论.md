# 弦图理论

以下只考虑无向图

## 弦图基本概念

导出子图（诱导子图）：$G'=(V',E')$ 为 $G=(V,E)$ 的导出子图当且仅当 $\forall (u,v)\in E,((u,v)\in E')\lor (u\notin V')\lor (v\notin V')$

团：完全子图

极大团：极大完全子图

最大团：点数最大的团

最小染色：用最少的颜色给每个点染色，使得任意边两端点不同色

最小团覆盖：用最少的团覆盖所有点

色数：最小染色的颜色数，图 $G$ 的色数记为 $\chi(G)$

独立数：最大独立集的点数，图 $G$ 的独立数记为 $\alpha(G)$

团覆盖数：最小团覆盖用到的团的数量，图 $G$ 的团覆盖数记为 $\theta(G)$

团数：最大团的点数，图 $G$ 的团数记为 $\omega(G)$

弦：连接环中不相邻两点的边

弦图：任意长度 $>3$ 的环都存在弦的图

## 基本性质

团数不大于色数（$\omega(G)\le \chi(G)$）：显然对最大团染色至少需要 $\chi(G)$ 种颜色

独立数不大于团覆盖数（$\alpha(G)\le \theta(G)$）：显然每个团中至多选择一点

弦图的任意导出子图一定是弦图

## 单纯点

**定义**：

- 点割集：$x$ 和 $y$ 间的点割集定义为满足删去集合中所有点后 $x,y$ 不连通的点集，要求 $x,y$ 不包含在点割集内

- 极小点割集：不含子点割集的点割集

- 单纯点：$\{u\}\cup N(u)$ 的导出子图是团的点

**性质**：

- 弦图上任意两点间的极小点割集的导出子图一定是一个团

  证明：

  - 对于点对 $x,y$ 考虑它们之间的极小点割集
  - 显然它们中任意一点均同时与 $x$ 和 $y$ 连通，否则删除之必然令点割集更小
  - 考虑点割集内任意两点 $a,b$，令 $a_1,a_2$ 为 $a$ 的邻居，$b_1,b_2$ 为 $b$ 的邻居，满足 $a_1,b_1$ 与 $x$ 连通，$a_2,b_2$ 与 $y$ 连通（这四个点不必在点割集内）
  - 考虑环 $a-a_1\sim b_1-b-b_2\sim a_2-a$，其中 $\sim$ 为最短路
  - 此环必然含有弦，且弦必然为 $a-b$
  - 从而极小点割集内任意两点之间有边，必然为团

- 任何弦图都有单纯点，非完全弦图有至少两个不相邻单纯点

  证明：

  - 考虑归纳，点数 $\le 3$ 时显然
  - 点数 $>3$ 时，对于完全图其每个点都是单纯点
  - 对于非完全弦图，取两不相邻点 $u,v$，令两者之间极小点割集为 $I$，去掉 $I$ 后 $u$ 所属连通块为 $A$，$v$ 所属连通块为 $B$
  - 若 $A\cup I$ 和 $B\cup I$ 都是完全图，则 $u,v$ 为一组不相邻单纯点
  - 若 $A\cup I$ 不是完全图，根据归纳假设 $A\cup I$ 含有至少两个不相邻单纯点 $x,y$，显然两者不可能同时在 $I$ 中，故必有一点在 $A$ 中，不妨设 $x\in B$；对于 $B\cup I$ 不是完全图的情况，同理可以得到 $x'\in B$ 为单纯点
  - 若 $A\cup I$ 是完全图而 $B\cup I$ 不是完全图，则 $x,u$ 为一组不相邻单纯点
  - 若 $A\cup I$ 不是完全图而 $B\cup I$ 是完全图，则选择 $x',v$
  - 若 $A\cup I$ 与 $B\cup I$ 都不是完全图，则选择 $x,x'$

## 完美消除序列

**定义**：排列 $p_{1\sim n}$ 为完美消除序列当且仅当 $\forall i$，$p_i$ 在 $p_{i\sim n}$ 的导出子图中为单纯点

**性质**：

- 一张无向图为弦图等价于存在完美消除序列

  证明：

  - 弦图必然存在完美消除序列：不断取出单纯点即可
  - 存在完美消除序列的必然为弦图：考虑图中每个环，完美消除序列中环第一次出现的点同其余所有点都有连边，显然点数 $\ge 4$ 时必然存在弦

### MCS 最大势算法

用于求出一张图的完美消除序列，也用于判定一张图是否为弦图

使用 $\text{MCS}$ 最大势算法 可以优化到 $O(n+m)$

**描述**：

- 初始序列为空
- 维护 $l_u$ 表示与结点 $u$ 相邻的点中已经在序列中的数量
- 每次取出 $l_u$ 最大的一个加入序列头部，并更新 $l$
- 这一过程容易优化到 $O(n+m)$
- 若为弦图，则最终得到的序列即为完美消除序列

**判断序列是否合法**：

- 设完美消除序列为 $p_{1\sim n}$
- 对于每个 $i$，令 $p_{i+1\sim n}$ 中与 $p_i$ 相邻的点依次为 $q_{1\sim k}$
- 若 $k>0$，只需要判断 $q_1$ 是否和 $q_{2\sim k}$ 相邻即可，因为团中剩余的边会在 $q_{1\sim k}$ 处依次判断

模板题：[SP5446 FISHNET - Fishing Net](https://www.luogu.com.cn/problem/SP5446) $\quad$ [代码](https://vjudge.net/solution/66937149)

### 最大团

令 $M(u)$ 表示完美消除序列中 $u$ 之后且与之相邻的点集，弦图的极大团一定可以表示为 $\{u\}\cup M(u)$ 的形式

从而弦图的团数为 $\max_u |M(u)|+1$，实际上等于 $\text{MCS}$ 算法得到的 $l$ 序列的最大值加一

### 最小染色

弦图的色数等于团数

构造：按完美消除序列的逆序按 $\text{mex}$ 贪心染色即可

模板：[P3196 [HNOI2008] 神奇的国度](https://www.luogu.com.cn/problem/P3196) $\quad$ [代码](https://www.luogu.com.cn/record/257555682)

### 最大独立集

构造：按完美消除序列从前往后，还没有标记则选上并将其邻域标记

模板题：[P3852 [TJOI2007] 小朋友](https://www.luogu.com.cn/problem/P3852) $\quad$ [代码](https://www.luogu.com.cn/record/257567135)

### 最小团覆盖

弦图的团覆盖数等于独立数

构造：对于独立集中的每个 $v$ 取 $\{v\}\cup M(v)$ 即可

## 区间图

给定数轴上若干区间，每个区间作为一个结点，相交的区间之间连边，得到的图称为区间图

区间图必然为弦图，所有区间按右端点从小到大排序后为一个完美消除序列
