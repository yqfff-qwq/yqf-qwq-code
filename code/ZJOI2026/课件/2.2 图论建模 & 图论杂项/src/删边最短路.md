# 删边最短路

## 形式

给定一张正权无向图，对于每条边，求出删去它后 $1$ 到 $n$ 的最短路

## 解法

建立到 $1$ 的最短路树和到 $n$ 的最短路树

取出 $1$ 到 $n$ 的最短路（若有多个则任选一个即可）

对于不在该最短路上的边，显然删去后 $1$ 到 $n$ 的最短路不变

枚举每条不在该最短路上的边 $(u,v)$（**正向反向分别枚举一次**），设 $u$ 和 $n$ 在到 $1$ 的最短路树上的 $\text{lca}$ 为 $x$，同理另一侧得到 $y$，则令 $1$ 到 $n$ 的最短路上 $x-y$ 之间的边的答案都对 $\text{dis}(1,u)+w(u,v)+\text{dis}(v,n)$ 取 $\min$

用一颗线段树维护链即可

时间复杂度 $O((n+m)\log n)$

## 例：[CF1163F Indecisive Taxi Fee](https://www.luogu.com.cn/problem/CF1163F)

设将 $(u,v)$ 边权从 $w$ 修改为 $w'$，则答案为删去 $(u,v)$ 后的最短路和 $\min(\text{dis}(1,u)+w'+\text{dis}(v,n),\text{dis}(1,v)+w'+\text{dis}(u,n))$ 的较小值，预处理删边最短路即可

时间复杂度 $O((n+m)\log n+q)$
